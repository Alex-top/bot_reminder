# Бот-напоминание для ВКонтакте

## Функционал
- Создание напоминаний: `через 10 минут`, `в 15:30`, `завтра в 10:00`
- Просмотр списка: `/list`
- Отмена: `/cancel ID`

## Технологии
- Python + vk_api
- SQLite для хранения
- Hors для парсинга времени

## Запуск
1. Установить зависимости: `pip install -r requirements.txt`
2. Настроить `.env` с токеном VK
3. Запустить: `python bot.py`
