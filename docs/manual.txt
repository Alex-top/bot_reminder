pytest tests/ -v

pip install pytest-cov
pytest tests/ --cov=. --cov-report=term

📦 Работа с виртуальным окружением
🔹 Активация виртуального окружения
В зависимости от ОС:

bash
# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
После активации в начале строки терминала появится (venv).

🔹 Установка зависимостей
bash

✅ Команды для работы (шпаргалка)
bash
# 1. Создать виртуальное окружение (если еще не создано)
python -m venv venv

# 2. Активировать
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Если нужно добавить новую зависимость
pip install имя_библиотеки
pip freeze > requirements.txt  # обновить requirements.txt

# 5. Запустить бота (из активированного venv)
python bot.py

# 6. Запустить тесты
pytest tests/ -v

# 7. Деактивировать окружение (когда закончил работу)
deactivate

Настройки возможности для отображения кнопок в боте:
Шаг 1. Включите «Возможности ботов» в настройках сообщества
Перейдите в Управление вашим сообществом:
https://vk.com/club238603541?act=edit

В левом меню выберите раздел «Сообщения»

Найдите подраздел «Настройки для бота» (или «Настройки бота»)

Включите опцию «Возможности ботов» (Bot capabilities / Chat bot feature)

Эта опция может называться иначе: «Включить возможность отправки клавиатур и callback-кнопок»

Нажмите «Сохранить»

Шаг 2. Включите Long Poll API
Перейдите в «Работа с API»:
https://vk.com/club238603541?act=api

На вкладке «Long Poll API» включите его (переключатель)

На вкладке «Типы событий» отметьте:

✅ Входящее сообщение

✅ Событие нажатия на кнопку (Message event / Callback event)

Шаг 3. Пересоздайте ключ доступа (токен)
На вкладке «Ключи доступа» удалите старый ключ

Создайте новый ключ, обязательно отметив:

✅ Сообщения сообщества

✅ Управление сообществом

✅ Фотографии

✅ Работа с callback API

Скопируйте новый токен и замените его в файле .env

Перезапустите бота
