Вариант 1: Установить последнюю стабильную версию hors (Настоятельно рекомендуется)
Самый простой и надежный способ — установить версию, которая гарантированно существует и работает. Попробуйте выполнить эту команду в вашем активированном виртуальном окружении (bot_remi):

bash

Эта команда установит последнюю доступную версию. Судя по информации с PyPI, последняя версия hors для Python — 1.1.3 или выше.

Что делать с requirements.txt:
После того как установка пройдет успешно, вам нужно будет обновить ваш файл requirements.txt, чтобы он запомнил правильную версию. Выполните:

bash
pip freeze > requirements.txt
Вариант 2: Установить конкретную существующую версию
Если по какой-то причине вам нужна не самая новая версия, а какая-то определенная, сначала нужно узнать, какие версии существуют. Для этого используйте команду:

bash
pip index versions hors
Она покажет все доступные версии. После этого вы сможете установить нужную, например:

bash
pip install hors==1.1.3
Вариант 3 (Запасной): Временно убрать hors из requirements.txt
Если библиотека hors не является критичной для самого первого запуска (а она используется для парсинга "сложных" фраз), вы можете пока что установить остальные зависимости без нее. Для этого:

Откройте файл requirements.txt.

Либо удалите или закомментируйте (поставьте символ # в начале) строку hors==0.3.0.

Затем снова выполните команду установки:

bash

Этот вариант позволит вам продолжить разработку, а hors вы сможете установить позже, когда разберетесь с версиями.
